## 7. Interaction & Motion Spec

- **Page loader:** matrix-digit CSS animation (9-digit 3x3 grid, green flicker/fall, radial glow) — plays briefly on load, fades out.
- **Hero:** cursor-proximity reveal — hovering near the portrait gradually reveals the cyborg version underneath (circular mask following cursor via `mask-image` + JS mousemove). Needs a mobile fallback (tap-to-reveal or slow auto-loop, since there's no cursor on touch devices).
- **About section:** word-level text-scatter-on-hover — words shift outward from cursor proximity (~100px radius), spring back smoothly on mouse-leave, subtle green color/glow shift on nearby words.
- **Service cards:** glassmorphism (frosted translucent bg, blurred backdrop, green glow border on hover) + tilt-on-hover (perspective rotate following cursor position) + expand-on-hover layout reflow using `animejs`'s `createLayout`/layout-diffing.
- **Scroll:** subtle parallax depth between sections/images.
- **Secondary buttons ("See more," etc.):** glassmorphism body + green blurred glow-blob effect on hover (Uiverse-based, recolored).
- **Primary CTA button ("Book a call" / WhatsApp):** also glassmorphism, but more saturated green tint/glow so it still reads as the primary action — not solid fill.
- **Footer social icons:** layered/skewed icon hover effect (Uiverse-based) reskinned to green, expanding into a glassmorphism profile-style tooltip card with name + tagline per platform (WhatsApp/Instagram/LinkedIn).
- **CTA section background:** static `cta-glow.png` with option to swap in `cta-glow.mp4` as a looping background video (silent, compressed, seamless loop required); slow pulsing glow or slow rotation if implemented via CSS instead.
- **Site-wide cursor trail:** a comet-tail light trail follows the cursor across the whole page — a chain of small glowing green segments/dots that shrink and fade out along the tail (not a single static glow blob). Each segment eases toward the position of the one ahead of it, so the tail has real lag/whip to it as the cursor moves. Hides while over the hero section (so it doesn't compete with the hero's own cursor-reveal effect). Must respect `prefers-reduced-motion` (disable entirely) and not render on touch devices (no cursor).

## 9. Quality Bar (per client-provided "$10K Website Checklist")

- **Motion restraint:** every individual motion effect above is intentionally subtle — but check the *combined* feel once assembled. If the loader + hero reveal + word-scatter + tilt-hover + cursor trail + layout-diffing cards feel like "a lot happening" together rather than each whispering, dial back intensity/frequency rather than removing effects outright. Motion should read as hand-crafted polish, not a slop of simultaneous animations.
- **Mobile is a separate design pass, not a shrink:** do not simply compress the desktop layout for small screens. Specifically reconsider on mobile: hero text placement (bottom-left may need to become full-width/centered on narrow screens), the 7-card service grid (stack thoughtfully, don't just go to 1 column with no spacing adjustment), and hover-dependent effects (word-scatter, tilt, cursor trail, footer tooltips) all need real tap/touch equivalents, not just "disabled on mobile."
- **Invisible technical quality (do not skip):**
  - Page load under 2 seconds — compress all images/video (`cta-glow.mp4` especially) before shipping.
  - WCAG AA color contrast — double check white/gray text on black background and green-on-black combinations actually pass contrast, not just "looks readable."
  - Keyboard navigation — all interactive elements (nav, buttons, footer social links) must be reachable/usable via keyboard, not just mouse hover.
  - Semantic HTML — proper heading hierarchy (one h1, logical h2/h3), nav/main/footer landmarks, alt text on all images.
  - Real meta tags — page title, meta description, and the Open Graph share image (still to be created, see section 8).
